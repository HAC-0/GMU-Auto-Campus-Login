# GMU 校园网自动登录助手 🚀

专为 GMU 校园网（Portal 认证）打造的轻量级开机自动登录工具。配置一次，开机静默连网，连通即退，零后台常驻。

---

## ✨ 功能特性

- **开机静默自启**：开机自动在后台发起认证，无需手动打开浏览器点登录。
- **即连即退（零内存占用）**：网络连通验证通过后自动终结进程，不驻留后台占用系统资源。
- **防“假在线”机制**：针对网关会话假死（显示已连接但无外网权限）的情况，内置自动注销与重连逻辑。
- **自动无感更新**：外网连通后自动检查 GitHub Releases 最新版本并完成无感热替换。
- **配置持久化**：首次启动配置学号与运营商后自动保存，修改密码或登录失败时自动弹窗引导。

---

## 📥 下载与使用

### 普通用户（推荐）

1. 前往本仓库的 [Releases 页面](https://github.com/HAC-0/GMU-Auto-Campus-Login/releases) 下载最新版本的 `校园网登录助手.exe`。
2. 双击打开程序，输入你的 **学号**、**密码** 并选择对应的 **网络运营商**（电信 / 移动 / 联通 / 校园网）。
3. 点击 **保存并登录**。
4. 提示保存成功后即可正常使用，后续每次电脑开机均会自动在后台连网，无需再次打开。

> **重置配置**：如需修改账号或密码，直接删除同目录下的 `config.json` 文件并重新打开软件即可。
